A Flutter monorepo.

## Commit convention

This repository **requires [Conventional Commits](https://www.conventionalcommits.org/)**, enforced both by a local git hook and by CI on pull request titles.

Format: `<type>(<scope>)?: <description>` — e.g. `feat(auth): add login screen`.

After cloning, enable the local commit hook once:

```bash
./.githooks/setup.sh
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full rules, allowed types, and examples.
